# Dominio de MySchoolMyParents Online

Dominio canónico:

- `myschoolmyparents.online`
- URL principal: `https://myschoolmyparents.online`

Usos previstos:

- página pública y política de privacidad;
- eliminación de cuenta y datos;
- dominio autorizado para Google Sign-In;
- redirect URI de autenticación cuando se implemente A16;
- enlaces universales de iOS y App Links de Android, si se habilitan.

Antes de activar A16 se debe configurar este dominio en el proveedor de identidad
elegido, crear las credenciales separadas para Android e iOS y registrar los
redirect URI exactos. Las credenciales y secretos deben mantenerse fuera del
repositorio.
