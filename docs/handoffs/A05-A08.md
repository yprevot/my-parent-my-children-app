# Entrega A05-A08 — fase 1

Estado: IMPLEMENTED_IN_CODE; pendiente de aceptación manual G2.

La fase 1 permite importar varias fotos, añadir fotos sucesivas a un libro y
mantener cada página como un trabajo OCR persistente. El worker recupera trabajos
interrumpidos, reintenta hasta tres veces con backoff de 1, 2 y 4 segundos y deja
el error aislado en la página que falló. El adulto puede aplicar recorte centrado o
rotación de 90 grados antes del OCR, reordenar páginas y revisar/editar cada
borrador antes de aprobarlo.

Al reprocesar una página aprobada, el texto anterior y su audio siguen disponibles
hasta que el nuevo borrador se aprueba. La aprobación reemplaza los párrafos de esa
página dentro de una transacción y la reordenación normaliza también el orden de
los párrafos.

Validación automatizada:

- `flutter analyze --no-pub`: sin issues.
- `flutter test --no-pub`: 12 tests correctos.
- `flutter build apk --debug`: APK generado correctamente.

Pendiente para declarar G2 verde: conectar el Samsung Galaxy S25 Ultra, probar
cámara, galería, permisos, páginas reales, cierre forzado, modo avión y verificar
que el OCR conserve el orden esperado. La prueba física en iOS y tablet queda para
